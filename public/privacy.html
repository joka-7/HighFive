פרטיות

עודכן לאחרונה ב-4 בנובמבר 2026

High5 מלמדת אנגלית לדוברי עברית, בדפדפן או באפליקציית Android. אין בה חשבונות משלה ואין שרת או מסד נתונים שמחזיקים את נתוני הלמידה שלכם, ולכן מי שמפעיל את High5 לא יכול לקרוא אותם.

מה נשאר במכשיר שלכם

ההתקדמות, הרמה, ההעדפות ומפתח ה-AI נשמרים באחסון של הדפדפן הזה (או של האפליקציה). שום דבר לא יוצא מהמכשיר אלא אם מפעילים אחת מהאפשרויות שלמטה.

אופציונלי: סנכרון עם Google Drive שלכם

אם בוחרים חיבור ל-Google Drive, נכנסים עם Google ו-High5 שומרת את הנתונים בתיקיית אפליקציה מוסתרת ב-Google Drive שלכם. היא מבקשת גישה רק לתיקייה הזו (ההרשאה drive.appdata), וגם שם וכתובת מייל כדי להראות מי מחובר. היא לא יכולה לראות, לרשום או לשנות שום קובץ אחר ב-Drive, והתיקייה המוסתרת גלויה רק לכם ולאפליקציה. אסימון הכניסה והמייל נשמרים במכשיר שלכם.

השימוש של High5 במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use. הנתונים מ-Drive משמשים רק לסנכרון בין המכשירים שלכם.

אופציונלי: תכנים מ-AI

אם מוסיפים ספק AI ומפתח API משלכם, הבקשות לתכנים (למשל הרמה שלכם והטקסט שאתם כותבים בתרגול שיחה) עוברות ישירות מהמכשיר לספק שבחרתם, תחת החשבון שלכם אצלו. הן לא עוברות דרך שום דבר ש-High5 מפעילה, ותנאי הפרטיות של הספק חלים. המפתח נשמר רק במכשיר.

אופציונלי: תזכורות יומיות

אם מפעילים תזכורות יומיות, הדפדפן נרשם לקבלת התראות דחיפה דרך Firebase Cloud Messaging של Google. השרת שומר רק אסימון התראה, אזור זמן ושני תאריכים (מתי השלמתם את המשימות ומתי נכנסתם) — בלי חשבון, בלי שם ובלי נתוני למידה. ביטול תזכורות מוחק את הרשומה.

האתר

האתר הוא קבצים סטטיים ב-Vercel. כמו כל שירות אחסון, Vercel עשויה לשמור יומני בקשות רגילים (כמו כתובת IP). סרטוני האזנה מוצגים מ-YouTube (youtube-nocookie), וקישורים לאתרים כמו BBC ו-TED נפתחים אצלם, ולכן השירותים האלה רואים את כתובת ה-IP שלכם כשמשתמשים בהם. High5 עצמה לא משתמשת באנליטיקס, בפרסום או בעוגיות מעקב.

מחיקת הנתונים

  • בהגדרות, תחת סנכרון ל-Google Drive, בחרו מחיקת הנתונים מ-Google Drive. זה מוחק את הקבצים של High5 מה-Drive ומבטל את הגישה של האפליקציה. מכשירים אחרים שעדיין מחוברים יעלו את העותק שלהם שוב, אז נתקו אותם קודם.
  • אפשר גם להסיר את הגישה של High5 ואת הנתונים המוסתרים שלה בעצמכם בחשבון Google, תחת אבטחה ← החיבורים שלך לאפליקציות ושירותים של צד שלישי.
  • בהגדרות, ביטול תזכורות מוחק את רשומת ההתראות מהשרת.
  • ניקוי נתוני האתר בדפדפן, או הסרת אפליקציית Android, מוחקים את העותק שבמכשיר.
