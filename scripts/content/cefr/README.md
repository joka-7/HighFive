# CEFR reference word lists

Used only by `scripts/audit-content.mjs` to check that each word is taught at a
sensible level. Copied unchanged from
[openlanguageprofiles/olp-en-cefrj](https://github.com/openlanguageprofiles/olp-en-cefrj)
(commit `d4e45b7`).

- `cefrj-vocabulary-profile-1.5.csv`: A1–B2. The CEFR-J Wordlist Version 1.5,
  compiled by Yukio Tono, Tokyo University of Foreign Studies (copyright Tono
  Laboratory at TUFS). Free for research and commercial use, provided the
  dataset is cited.
- `octanove-vocabulary-profile-c1c2-1.0.csv`: C1–C2. The Octanove Vocabulary
  Profile C1/C2 1.0, by Octanove Labs, under the
  [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
  licence.

Neither list's authors are responsible for any inaccuracies in them.
